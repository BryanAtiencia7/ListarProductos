# Proyecto en Node
## Requisitos
En la carpeta donde se alojan los micros se deben correr los siguientes comandos:

```
npm init -y
npm i express mysql2
```
## Ejecutarlo

```
node listar_productos.js
http://localhost:5000

node agregar_producto.js
http://localhost:5001

```
